Static files and the MIME map

  • /static/ — a second document tree
  • /static/css/style.css — text/css
  • /static/image.png — image/png
  • /static/img/marcampo.jpg — image/jpeg
  • /static/data/demo.json — application/json
  • /big.txt — text/plain, and a large read

Directory handling

  • /autoindex/ — generated listing (autoindex true)
  • /idxdir/ — per-location index
  • /directory/ — index youpi.bad_extension, the 42 tester fixture

CGI

  • /forms.html — GET and POST forms against the scripts
  • /cgi-bin/greet.py — a plain 200 from a script
  • /cgi-bin/envdump.py — the environment, incl. cgi_param
  • /cgi-bin/echo.py?a=1&b=2 — method, query and body as text
  • /cgi-bin/upload.py — upload form and handler
  • /directory/youpi.bla — CGI matched by \ .bla suffix

Methods and uploads

  • /uploads/ — POST writes here, DELETE removes
  • /readonly/ — limit_except GET + autoindex; DELETE answers 405

Redirects and errors

  • /ext — 302 to another host
  • /old — internal return (known bug: answers 500)
  • /nope — 404 error page
  • /quiet/nope — same page, forced to 200 by error_page … =200
